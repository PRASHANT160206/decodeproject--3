# ⚡ Interactive Web Elements

## DecodeLabs — Frontend Development Project 3

This project is created as part of the DecodeLabs Frontend Development
Project 3: **Interactive Web Elements**.

The main objective is to add interactivity to a webpage using JavaScript,
buttons, toggles, dynamic content and DOM manipulation.

---

## 📌 Project Objective

The objective of this project is to demonstrate how JavaScript can be
used to make a webpage interactive and responsive to user actions.

### Main Requirements

- Buttons and toggles
- Basic user interaction
- Dynamic content updates
- JavaScript fundamentals
- DOM manipulation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Responsive Web Design

---

## ✨ Features

### 1. Dark / Light Mode

Users can switch between light mode and dark mode by clicking the
theme button in the navigation bar.

### 2. Interactive Button

The "Show Message" button dynamically displays a message using
JavaScript.

### 3. Click Counter

The counter includes:

- Increase button
- Decrease button
- Reset button

The counter value changes dynamically without refreshing the webpage.

### 4. Dynamic Greeting

Users can enter their name and click the "Greet" button.

JavaScript dynamically generates a personalized greeting.

The Enter key can also be used to submit the name.

### 5. Random Frontend Tips

The "Generate Tip" button displays a random frontend development
tip every time it is clicked.

### 6. Responsive Design

The webpage is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices
